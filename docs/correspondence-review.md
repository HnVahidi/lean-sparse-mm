## Theorem 4

- **Problem and arithmetic.** The index and processor type is `Fin n` with `n > 0`. All three masks have at most `d` positions in each row and each column. `SupportedBy` requires zero outside each input mask and permits zeros inside it. The output mask gives the positions that must be computed, including zero answers. The full product may be dense. Its semiring identities retain the order `U i j * V j k` and regroup only addition. [Masks](../SparseMM/Masks.lean) · [Arithmetic](../SparseMM/Algebra.lean)
- **Parameters and ownership.** The Lean statement takes every positive `d`, which includes the paper's `1 ≤ d ≤ n` range. The type of an allowed input entry distinguishes its left or right matrix and its coordinate. The public map `original` assigns one holder per entry and bounds the combined initial load by `K*d`. The output map assigns every requested coordinate exactly one holder, with at most `d` per holder. Fixing `K` across the instance family gives the paper's `O(d)` initial load. The introductory example about one row per machine describes an earlier setup. The theorem follows the general bounded distribution in Section 2.1. [Main statement](../SparseMM/Main.lean)
- **Public information and quantifier order.** The masks, holder map, and sparsity/load bounds precede the existential choice of the output map and program. Correctness then quantifies over every pair of numerical matrices supported by those masks. Initial views give each machine exactly its assigned entries, with absent records at other machines. The proof therefore gives one public code and one output assignment for all values admitted by the same public instance. Every code phase prepares from the sender's local state and collects at the receiver using its own state and delivered packets. [Local execution](../SparseMM/LocalPipeline.lean) · [Program](../SparseMM/Program.lean)
- **Port constraints.** Each static phase carries a proved legal slot assignment. The slot condition distinguishes labelled packets and prevents a same-slot conflict at either port. Actual sends read the source's local memory, actual receives come from those sends, and the model proves delivery and both capacity bounds. A sender and receiver may act simultaneously at the same machine. Self-destined records stay local. The five phases execute sequentially and their lengths sum to the stated round count. [Routing](../SparseMM/Routing.lean) · [Network semantics](../SparseMM/Model.lean)
- **Nonvacuity.** For `n = 2`, `d = K = 1`, take one requested coordinate `(0,0)` and one allowed coordinate `(0,0)` in each input. Assign the left entry to machine zero and the right entry to machine one. Values two and three over the natural numbers give the requested answer six. The assumptions also admit clustered instances. With `n = d = 4` and full masks, `K = 2` allows each machine to hold one row of each input, and the rounded threshold twelve permits extracting a cluster.

The proof constructs its public plan from the assumptions of the theorem. In particular, clustering and residual sparsity come from finite extraction, the cluster count yields enough helper slots, and the finite balancing and routing proofs produce each placement and schedule. The plan contains bounds and slot legality as certified fields, whose witnesses the proof supplies. The local execution proves numerical correctness separately. It establishes each availability fact from the preceding phase, and the semiring proof gives the final answer. [Plan construction](../SparseMM/Plan.lean) · [Correctness](../SparseMM/Program.lean)

The exact natural round budget is the sum of the five scheduled lengths. The checked inequalities give at most `(4*K + 40)*d*(Nat.sqrt d + 1)` rounds and at most `(8*K + 80)*d*Real.sqrt d` after coercion to the reals. ## Word encoding and public computation

The main Lean statement transports one semiring scalar per message. Its independent wire theorem reconstructs the logical packet label from the public slot and proves equality of the coded and scalar receive operations when decoding inverts encoding on actual transmitted values. The manuscript's bit-level interpretation therefore requires a codec available to the communicating machines, lossless on the transmitted input entries, products, and partial sums throughout the admissible input family. A codec selected privately for a particular numerical execution would provide a different assumption. The checked interface is a per-receive preservation theorem for an arbitrary code type. A finite code-cardinality bound and a composed bit-budget program remain outside the formal statement. [Wire bridge](../SparseMM/Wire.lean)

The witnesses use classical finite choice. The code is deterministic once its public choices are fixed. In the paper's free local computation model, a common finite search over the public masks, bounded cluster lists, assignments, and slot maps can choose the same valid plan at every machine. This supplies the mathematical uniformity argument. The Lean result is a formal existence proof with operational execution semantics. An extracted computable planner and the manuscript's exact lexicographic selection rule are separate specifications. ## Lower-bound algorithm class

`BroadcastLower.System` has arbitrary state and message types. Each outgoing message is a function of round, sender identifier, and sender-local state. The incoming view retains both sender identity and silence. The broadcast lower bound compares the two executions whose initial configurations differ only at the source. One changed sender can affect distinct recipients across those executions, giving the factor three. The proof holds even for the larger class that can receive multiple messages.

The aggregation bounds use independent input bits, a fixed designated receiver, and one receive port on **every** input and every round before the common time bound. The local output and message-address decisions can depend on local state. The proof represents each next-state observable as its empty-inbox value plus sender corrections. Each correction uses two prior local states, which doubles the cylinder-degree bound. The all-input receive condition is essential to that identity. The full-degree argument applies to OR and AND, and a local positive-sum test reduces exact counting to OR. These are deterministic, fixed-time bounds at a designated output holder.
